## What's New

- **Display Options:** Now the application can be configured to set the monitor and display options in the `RaidViewer.ini` file.
  - **Monitor:** `2` - Selects the second monitor.
  - **Mode:** `Window` - Sets the display mode to windowed.
- **Images Folder Location:** The image folder path can now be configured via `[Images] Folder` in `RaidViewer.ini`, supporting relative and absolute paths, with graceful handling if the directory is missing.
